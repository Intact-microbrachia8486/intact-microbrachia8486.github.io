Portfolio Analysis Engine

Live

A from-scratch analytics tool that pulls a live brokerage account and runs a CAPM skill-vs-luck attribution — separating market/sector exposure (β) from benchmark-independent return (α), with a t-test on whether any edge is statistically real. Also computes Sharpe, drawdown, FIFO-matched realized P&L, concentration, and risk flags. No web framework — just the Python standard library.
